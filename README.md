# Highfly Document Clearing FZ-LLC - Website

A professional, responsive website for **Highfly Document Clearing FZ-LLC**, a UAE-based document clearing company specializing in visa services, document attestation, PRO services, and other government documentation services.

## Features

- **Responsive Design**: Fully responsive and mobile-friendly
- **UAE Standards**: Compliant with UAE regulatory requirements and branding
- **Professional Layout**:
  - Header with logo and navigation
  - Hero section with compelling CTAs
  - Services showcase (12+ services)
  - Why Choose Us section
  - How It Works process steps
  - Statistics counter with animations
  - Testimonials section
  - Authorities partnership showcase (GDRFA, ICA, MoHRE, DED, MOFA, MOE, etc.)
  - Contact form and information
  - Comprehensive footer

- **Modern Design**:
  - UAE color scheme (Navy Blue + Gold)
  - Smooth animations and transitions
  - Interactive elements
  - Professional typography

- **Services Offered**:
  - Visa Services (Tourist, Employment, Residency, Golden Visa, Student)
  - Emirates ID Services
  - Document Attestation & Legalization
  - Trade License Services
  - PRO Services
  - Ejari Registration
  - Business Setup
  - Medical Fitness
  - Labor Card Services
  - Driving License
  - Typing Center

## Running Locally

### Option 1: Using Python (Recommended)
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```
Then open: http://localhost:8000

### Option 2: Using Node.js http-server
```bash
npm install -g http-server
http-server
```
Then open: http://localhost:8080

### Option 3: Using PHP
```bash
php -S localhost:8000
```
Then open: http://localhost:8000
